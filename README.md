# Overcomplicated Bees

A full codebase rewrite of Complicated Bees for modpack and customizability purposes.

## About

Overcomplicated Bees is a Minecraft mod that adds a comprehensive bee breeding system, similar to Complicated Bees. It includes:

- Genetics system: Bees have genomes with chromosomes that determine their traits
- Data-driven species: Bee species are defined through data packs, easy to add new bees
- Trait inheritance: Offspring inherit genetic traits from parents
- Environmental requirements: Bees have specific temperature, humidity, and flower preferences
- Production system: Different bee species produce unique products
